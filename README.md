# galass-ci

CI **produit** des dépôts Galass (`Galass_Driver`, `Galass_Rider`, `Galass_backend`, `galass-emu-actions-pub`) : ce dépôt ne contient que ce qui teste, vérifie ou déploie le produit — aujourd'hui `isa-human-tick.yml`, qui coche une claim `[scope:human]` d'une ISA d'un dépôt Galass via la liste blanche `opencode/allowed-repos.sh` ; l'inventaire complet du nettoyage est dans `CLEANUP.md`. Le harnais opencode / FullRun / agents / prompts générique ne vit plus ici : les runs opencode sont désormais déclenchés et maintenus dans [`LordThiouk/lifeos-ci`](https://github.com/LordThiouk/lifeos-ci) (`opencode-fullrun.yml`, `task.yml`, scripts `opencode/` et leur suite de tests).
